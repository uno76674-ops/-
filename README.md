# Инструкция: Разгон дохода на буксах

Современный, адаптированный одностраничный сайт, созданный для привлечения рекламодателей на платформах Aviso.bz, WMRFast.com и SEO-FAST.ru.

## 🎯 Цель проекта
Конвертация целевого трафика (админы Telegram-каналов, арбитражники, SEO-специалисты) в активных рефералов-рекламодателей для получения пассивного дохода от их рекламных бюджетов.

## 🛠️ Стек технологий
* **HTML5** — структура и контент страницы.
* **CSS3** — встроенные стили, адаптивная неоновая бизнес-тема (Mobile First).

## 📂 Структура проекта
* `index.html` — основной файл одностраничника.
* `README.md` — описание проекта и инструкция.

## ⚙️ Инструкция по настройке перед запуском
1. Откройте файл `index.html` в редакторе кода.
2. Найдите и замените следующие заглушки на свои реальные реферальные ссылки:
   * `ВАША_РЕФЕРАЛЬНАЯ_ССЫЛКА_AVISO`
   * `ВАША_РЕФЕРАЛЬНАЯ_ССЫЛКА_WMRFAST`
   * `ВАША_РЕФЕРАЛЬНАЯ_ССЫЛКА_SEOFAST`
3. Сохраните изменения в файле.

## 🚀 Развертывание (Деплой)
Сайт полностью готов к бесплатному размещению на **GitHub Pages**.
